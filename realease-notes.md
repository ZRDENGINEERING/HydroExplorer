First public beta of HydroExplorer: a Windows data explorer for HEC-RAS and HEC-HMS projects.

**Install:** unzip and run `HydroExplorer.exe`. No .NET install needed (self-contained, Windows x64).

**Heads-up**
- The exe is unsigned, so Windows SmartScreen may warn on first run ("More info" → "Run anyway").
- The project browser is currently rooted at `C:\Temp\`; place or link your projects there.
- HEC-RAS 2D support is experimental (sampled cell-result overlay only).
- Beta software; not a substitute for professional engineering judgment. See the Disclaimer in the README.
